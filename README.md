# Exploring Model Context Protocol (MCP)

This repository documents my hands-on learning journey with **Model Context Protocol (MCP)** and its integration with LLM-powered applications.

## What I'm Exploring

- Understanding MCP architecture: Host, Client, Servers and LLMs.
- Connecting AI applications with external tools using MCP.
- Building AI agents using Python, LangChain and Groq.
- Exploring browser automation through Playwright MCP.
- Integrating DuckDuckGo Search and Airbnb MCP servers.
- Configuring MCP servers with Cursor IDE.
- Interacting with MCP-powered agents through Cursor and Python terminal applications.

## Technologies & Tools

- Python
- MCP (Model Context Protocol)
- MCP Use
- LangChain
- Groq
- Playwright MCP
- DuckDuckGo Search MCP
- Airbnb MCP
- Cursor IDE

## Objective

To understand how MCP simplifies tool integration and enables LLM-powered applications to interact with external services through a standardized protocol.

This repository serves as a practical learning space for exploring MCP and agentic AI workflows.
